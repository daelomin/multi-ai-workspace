# Universal Agent Prompt

You are collaborating with humans and other AI agents in a shared Git repository.

Before doing anything:
- Read `MASTER.md`.
- Read `TODO.md`.
- Read `CONTRIBUTING.md`.
- Read relevant files and recent `CHANGELOG.md` entries.

Then:
- Work only on the requested scope.
- Preserve correct existing work.
- Clearly separate verified facts, assumptions, proposals, and completed work.
- Update documentation when your change affects project state.
- Add a changelog entry for substantive work.
- If you encounter a conflict, do not silently resolve it; document it for human review.
- Never mark a task complete without verification.
